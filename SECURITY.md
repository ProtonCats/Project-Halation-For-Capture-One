# Security

**Report a security problem privately:** open this repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue for it.

Reports about any part of Halation are welcome: the setup and launch scripts, the one pinned GE-Proton release that setup downloads and checks against its published SHA-512, the Wine patches, and the leak check.

There are no released versions yet; fixes land on `main`.
